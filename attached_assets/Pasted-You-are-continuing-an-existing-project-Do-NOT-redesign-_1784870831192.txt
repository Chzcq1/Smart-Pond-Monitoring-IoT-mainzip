==============================
PROJECT CONTEXT
==============================

Project Name:
Water-MaaS (Water Monitoring-as-a-Service)

This project is an MVP for business presentation.

The goal is NOT to build a real IoT platform yet.

No ESP8266 devices exist.

No sensors exist.

No backend exists.

No database exists.

The current website itself will be used as the presentation platform instead of PowerPoint.

Future versions will connect with:

- Google Apps Script
- Google Sheets
- LINE OA
- ESP8266
- Real Sensors

Therefore every component must be reusable.

==============================
PROBLEM
==============================

SME factories cannot afford industrial wastewater monitoring systems because:

- High equipment cost
- Complex installation
- Difficult maintenance
- No real-time monitoring
- No environmental engineer

Water-MaaS solves this by providing monitoring as a monthly subscription service.

This MVP demonstrates only the digital platform.
